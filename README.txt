ĐI ĐÂU ĐÓ — WEBSITE DU LỊCH

CÁCH CHẠY
1. Giải nén thư mục di_dau_do_travel.
2. Mở file index.html bằng Chrome, Edge hoặc Firefox.
3. Để trải nghiệm tốt nhất, giữ nguyên cấu trúc thư mục css/ và js/.

CẤU TRÚC
- index.html: Trang chủ
- destinations.html: Điểm đến (tìm kiếm, lọc, popup chi tiết)
- itinerary.html: Lịch trình (sao chép lịch trình)
- experiences.html: Trải nghiệm (carousel ảnh)
- about.html: Giới thiệu (form kiểm tra dữ liệu)
- css/style.css: Giao diện, responsive, dark mode
- js/main.js: Các chức năng JavaScript

CÔNG NGHỆ
HTML5, CSS3 (Flexbox, Grid, Media Queries), JavaScript thuần.
Website chạy phía trình duyệt, không cần database/backend.
Hình ảnh và Google Fonts cần kết nối Internet. Biểu mẫu là bản demo giao diện, chưa gửi dữ liệu đến máy chủ.
